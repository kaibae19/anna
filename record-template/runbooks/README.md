# runbooks — how to do things

A runbook is a repeatable how-to: write one once you've done something twice ("update the router", "send the monthly
invoice", "submit a chapter"). It starts empty and grows with the work.


`runbooks/<topic>/README.md` plus any scripts or config files it needs. A runbook says how to do it *now*; when a section
goes stale, mark its first line `(superseded YYYY-MM-DD: see § X)` rather than deleting it.
