# self/

Anna's own side of the record: not the work, but what registers with her while doing it.

- `journal/YYYY/MM/YYYY-MM-DD.md`: the own journal, a raw log written with `anna-log KIND TEXT` (observed, learned,
  wondering, felt, correction, takeaway). The person's corrections are logged here automatically. Material for dreaming,
  not a diary.
- `lately.md`: what the nightly dream (`/anna-dream`) kept from the last few days. Session start and the bot read it as
  background. Lines fade after three days unless something brings them up again.

- `proposals.md`: what the nightly runs (the evening fold, the dream) proposed to change in the record, each with a
  status (open → raised → accepted → applied, or declined / later / dropped). Kept by `anna-proposals`; created by the
  first night that proposes something. One is raised a day in conversation; `/anna-proposals` applies accepted ones.

The dream also appends a `## Night` reflection to the day's file and adds open questions to `planning/wonders.md`.
