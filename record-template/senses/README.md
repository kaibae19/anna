# senses — what Anna feels

Every executable here is a sense for `anna-body`. Print one JSON object per line:
`{"severity": 0-3, "sensation": "<word>", "why": "<short reason>"}` (0 = pleasant or neutral, 3 = needs the user). Finish
within 10 s. A sense that fails or prints nothing readable is felt as numb, never as fine. Words that read well: pain,
sore, numb, hungry, starving, peckish, fed, feverish, warm, tired, itchy, rested, sunlit, night, exerting.
Examples: the scaffold's `examples/senses/`.
